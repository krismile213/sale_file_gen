## 2. 五类 sheet 的坐标规格

### 2.1 每日销售数据（append 面：每天往尾部加订单行）

| 项 | 规格 |
|---|---|
| 表头行 | 行2（北美系冻结 y3，行1 是标题行；其余冻结 y2） |
| 冻结窗格 | 欧盟/阿联酋 `x12+y2`，北美/Interflowd北美 `x12+y3`，日/沙/澳/印 `x1+y2` |
| autoFilter | `A2:AR{末行}`（随数据行扩展） |
| 辅助列（欧盟英国版） | `AP=LEFT(C3,10)` 下单日；`AQ=IF(AND(E3<>"Cancelled",MID(G3,1,7)="Amazon."),1,0)` 有效性；`AR=IF(G3="Amazon.co.uk","英国","欧洲")` 地区 |
| 辅助列（北美版） | 同上，但 AQ 额外 `OR(LEFT(AO3,4)="TEMU")` 放行 TEMU 单（AO=merchant-order-id） |
| ⚠️ | AO2 表头原文 `order-item-id ` **带尾随空格**；日本表头乱码按列位定位 |
| duplicateValues 条件格式 | 重复订单行高亮（每份都有 1-3 条） |

程序动作：`append` 订单行 + 辅助列公式下拉；扩展 autoFilter 范围。

### 2.2 可售 / 在途库存（替换面：每天整表覆盖报告值）

| 项 | 规格 |
|---|---|
| 冻结窗格 | `x1+y3`（沙特可售 `x0+y3`、墨西哥可售 `x0+y3` 例外，不冻列） |
| 数据起点 | 行3 起（行2 表头），A=SKU，Y 列起为加工列 |
| 加工列 | 在途表 `在途 = Y=P+Q+R`（三态在途之和）；行3 起公式已铺 |
| 数据验证 | 可售库存 sheet 各有 1 个 |
| 特例 | 北美把可售（墨西哥可售库存）和在途（墨西哥在途库存）拆成两个 sheet；沙特/澳/印/阿联酋也是"可售""在途"分表；欧盟/日本/Interflowd北美是"可售+在途"合一表 |

程序动作：从结余报告粘贴**可售列**、清单报告（afn-*）粘贴**在途列**，Y 列公式保留不动。

### 2.3 库存记录（横向加列面：每天右侧加 1 列快照）★核心

以「英国库存记录 」（sheet 名**尾随空格**）实测：

| 行 | 内容 | 实测样例 |
|---|---|---|
| 行1 | 列合计 | `=SUM(R$5:R$20111)`（部分历史列被粘成静态值 28852 等，新列一律写公式） |
| 行2 | 标签 | 「在途库存」/「可售库存」 |
| 行3 | 星期文本 | 「周日」「周一」…（**纯文本**，供公式判断周末） |
| 行4 | 真日期 | 2026-08-16（序列 46250），格式 `m/d` 或 `yyyy/m/d` |
| 行5+ | 每 SKU 一行（B 列=SKU，autoFilter A4:B451） | 公式见下 |

新列公式（原样抄自 R5/R6）：
```
=IFERROR(IF(OR(R$3="周六",R$3="周日"),"",SUMIF('英国可售+在途库存'!$A:$A,$B:$B,'英国可售+在途库存'!$Y:$Y)),0)
```
- 周末列公式照写，靠 `OR(R$3="周六",...)` 自行留空，**不要跳过周末列**（保持日期连续）。
- SUMIF 第三参数是库存表的数据列：英国记录拉 `$Y:$Y`，其他表按各自"可售"/"在途"列对号。
- dims 已达 `A1:XCS451`（16000+ 列）＝历史日积月累；**新列接在最右有内容列 +1**，样式（边框/数字格式/列宽）复制左邻列。
- 北美每国有独立库存记录；Interflowd北美还多「美国/加拿大预留库存记录」两个 sheet（结构同款，SUMIF 拉预留列）。
- 条件格式：`AND(C5=0,C5<>"")` 缺货红标 + x14 扩展 3-4 条，加列时**条件格式范围会自动跟随**（同列样式复制即可）。

### 2.4 每日库存分析表（货件跟踪面：横向加货件列 + 纵向 SKU 行）

以「英国-每日库存分析表」实测（tabColor=红 FFFF0000，全部同款）：

| 行 | 内容 | 实测样例 |
|---|---|---|
| 行1 | I 列起 = **FBA 货件号** | `FBA15LWPXG5F` |
| 行2 | H2=「发货日期」，I 列起=发货日文本 | `6/9`、`7/7` |
| 行3 | H3=「预计时效」，I 列起=天数 | `35`、`15` |
| 行4 | H4=「预计到货」，I 列起=真日期 | 2026-07-14 |
| 行5 | 表头：A=SKU B=型号 C=站点 D=marketplace E=预留库存 F=可售库存 G=在途 H=调拨在途合计，**I 列起=货件描述** | `7/28卡航8/28到货正在接收` |
| 行6 | SUBTOTAL 合计行 | `=SUBTOTAL(9,I7:I1280)`；A6=`=SUBTOTAL(3,A7:A1258)` |
| 行7+ | 每 SKU 一行 | 货件列=发货数量；H 列=调拨合计公式（见下） |

H 列「到货自动剔除」公式（原样抄录）：
```
=IF(ISNUMBER(FIND("到货",$I$5)),0,IF(I7="",0,I7))+IF(ISNUMBER(FIND("到货",$J$5)),0,IF(J7="",0,J7))+...
```
- **到货 = 在行5 列头文字里追加「到货」**，H 列合计自动把该票剔除——程序到货日只改行5 一个单元格。
- 「正在接收」字样也写在行5 列头，条件格式 `NOT(ISERROR(SEARCH("正在接收",I5)))` 会变色。
- CQ 列：`=_xlfn.XLOOKUP(A7,'英国可售+在途库存'!A:A,'英国可售+在途库存'!C:C)` 拉 ASIN。⚠️ openpyxl 写 XLOOKUP **必须带 `_xlfn.` 前缀**，否则打开报 #NAME?。
- 冻结 `x24+y6`（北美系 `x34+y6`，欧洲分国表 `x7/x8+y7`）；行高 1275 个自定义行（每 SKU 行都调过高）。
- 条件格式全套：`CP7="保底"`、`LEN(TRIM(A7))>0`、缺货/新品未上架/销量超标（分国表 `AND($F7<$G7/2,$G7>2)` 等）、`I$1=""`、`I4<库存明细!$A$1`（美客多版）。
- 新货件加列动作：行1 货件号、行2 发货日、行3 时效、行4 预计到货（真日期）、行5 描述；数据列复制左邻列样式；SUBTOTAL/调拨公式范围扩展。

### 2.5 透视图 sheet（真透视 vs 手工模拟）

- **真透视**（欧盟英国/北美/Interflowd北美）：openpyxl 保留 pivotTable 部件但**不刷新缓存** → 在 `pivotCacheDefinition` 设 `refreshOnLoad="1"`，WPS/Excel 打开自动刷新（trunk `wps_fidelity.py` 已有此逻辑，复用）。
- **手工模拟**（日/沙/澳/印/阿联酋/美客多/罗马尼亚）：本质是普通表格，列头带 COUNTIF 漏单校验条件格式（`COUNTIF($D:$D,S5)=0` = 出现在汇总但不在明细 → 红标）。程序直接写值 + 保留条件格式即可。
- 共同校验逻辑（`AND(COUNTIF($G:$G,B10)>0,COUNTIF($B$10:$B$360,B10)-COUNTIF($B$10:B10,B10)=0)`）= 汇总行与明细行的去重比对。
- 「Sheet1」隐藏校验页（北美/沙/澳/印/阿联酋/美客多/罗马尼亚都有）：`SUM(G2:R11490)=SUM(S2:S11490)` 恒等式自检——**程序不要动这个 sheet**。

## 4. 程序每日更新动作序列（建议顺序）

```
① 可售/在途库存 sheet   ← 粘贴当日报告值（只写值区，加工列公式不动）
② 库存记录 sheet        ← 右侧加 1 列：行1 SUM 公式 + 行2 标签 + 行3 星期文本
                          + 行4 日期 + 行5起 SUMIF 公式（样式复制左邻列）
③ 每日库存分析表        ← 新货件加列（行1-5 四件套+描述）；到货日改行5 加「到货」
④ 每日销售数据          ← append 订单行 + AP/AQ/AR 辅助公式；扩 autoFilter
⑤ 手工透视图 sheet      ← 程序重算写入（假透视）
⑥ 真透视表              ← refreshOnLoad（打开时自动刷新，不写值）
⑦ openpyxl 另存后跑 apply_fidelity 回填 WPS 部件/缩略图/批注 VML
```

## 5. 已知陷阱清单（写程序前必读）

1. **sheet 名尾随空格**：`英国库存记录 `、`欧洲库存记录 `（欧盟）、`墨西哥-每日库存分析表 `（北美）。引用时 strip 匹配，写入时保留原名。
2. **AO2 表头 `order-item-id ` 尾随空格**（每日销售数据辅助列定位）。
3. **XLOOKUP 要写 `_xlfn.XLOOKUP`**，否则 #NAME?。
4. **行3 星期是文本**不是日期格式化——写「周六」「周日」四个字符按原文（「周六」非「星期六」）。
5. 库存记录 SUM 范围 `R$5:R$20111`、分析表 SUBTOTAL 范围各行不一（1258/1280/15212）——**照抄同 sheet 既有列的范围上界**，别自己算。
6. 美客多「库存明细」有 **30 个合并单元格**；写值前先读 merge 范围。
7. 日本「每日销售数据」表头乱码 → 一律按**列位**（A..AG）不按表头文字。
8. 美客多/罗马尼亚「产品类型」sheet 的「X月销量」是**静态列头**（手写的），换月要程序改文字。
9. 欧盟「多国库存」sheet 的 autoFilter 范围（A2:F2420）与 dims（H2407）不一致——历史遗留，别"修"它。
10. 冻结窗格数值因表而异（y2/y3/y5/y6/y7），**不要统一写死**，按 §2 各表规格。
