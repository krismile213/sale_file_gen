## 三、跑程序

```bash
cd C:\Users\dell\Desktop\work-main\sale_file_gen\Daily_Sales_Report\daily_update
C:\Python314\python.exe runner.py            # 正式跑
C:\Python314\python.exe runner.py --dry-run  # 只预览不动文件（推荐先看一眼）
C:\Python314\python.exe runner.py --only 日本,澳大利亚   # 只跑某几份
C:\Python314\python.exe runner.py --snap <快照目录绝对路径>   # 手工指定目录（一般不用）
```

程序每天自动做的事（=人工步骤的复刻，样式不动）：

1. 库存 sheet：按报告替换值（新增 SKU 追加行，消失 SKU 清值）
2. 库存记录：右侧按日加列（周末也占位写公式，行1 汇总、行3 星期、行4 日期）
3. 每日销售数据：按订单号去重后追加新订单
4. **锚点格滚动**（"组合跟着更新"）：日本/沙特/澳/印/阿联酋/Int澳/Int阿联酋的"下载日期"格 → 快照日
5. 保真回填：customXml/缩略图/打印设置/透视刷新标记（openpyxl 保存后补回）
6. 备份：改前自动备份到 `.workbuddy\backup_daily_YYYYMMDD\`

**缺报告不报错**：某份没导就自动跳过该项并在输出里提示 `[缺报告]`，其余照常。

## 六、月底换月（11 月初，10 月数据收口后）

1. 先跑一次全量 runner（用最后一天的快照），确认当月件数
2. 改 `month_rollover.py` 顶部常量（一次换月改一处月份）：
   - `ARCH_HI = "2026-11-01"`、`ANCHOR_D = date(2026,11,1)`（下月1天/锚点=下月1日）
   - `OCT_LO = "2026-10-25"`（11月表保留 10-25~10-31 = 上月最后7天 + 11月）
   - `ARCHIVE_DIR` / `ARCH_PREFIX` → `2026年10月`
   - `SEP_PROG` → 填 10 月程序件数（跑完 runner 从输出汇总，或用 `sep_compare.py` 改月份）
3. `python month_rollover.py --dry-run` → 核对每份文件的变更计划 → `--apply`
4. 换月自动完成：9月件归档进 `2026年每日数据\2026年9月\`（含记录列裁到 11-01、锚点定格 11-01、DAY 公式重定向）+ 根目录开 11 月新版（销售删到只剩 10-25 起）

## 七、备案：促销期窗口扩大（暂不写代码，人工执行）

**口径**：当月表保留【上月 N 天 + 当月整月 + 下月 1 天】，N 默认 7；大促（Prime Day、黑五等）前后可扩大。

- **换月前就知道要扩**（如 N=14）：改 `month_rollover.py` 的 `OCT_LO`（例：11月表想留 10-18 起 → `OCT_LO = "2026-10-18"`）即可，其余不动。库存记录/分析表列不受影响。
- **月内临时要扩**（10月版已删过 9-23 以前的行）：已删的行**去 9 月归档件里找**（`2026年每日数据\2026年9月\2026年9月-*.xlsx` 的每日销售数据，按日期段筛出后整块复制回 10 月版表尾，样式随粘贴走）；也可以把归档件当只读底稿用公式跨簿引用，但推荐直接复制。
- **促销期间临时多留未来列**：无需处理——库存记录/分析表本来就每天加列，促销不改变加列逻辑。
- **读数注意**：透视图"上月/当月"分桶由锚点/TODAY 驱动（沙特/澳/印/阿联酋/Int阿联酋跟随系统日期，日本/Int澳跟随锚点格）。窗口扩大后"上月"桶可能混入更早的数据，汇报时口径说明一句。

## 八、已知的坑（遇事先查这里）

- 北美销售表范围会含 10-01 的单（时区截头），归档按 ≤10-01 保留，是"下月1天"口径，不是错行

- **程序写入的订单号列是文本**（与人工一致）；若看到 `1.7E+14` 是列太窄，拉宽即恢复，不是数据坏了
- 2026-10-10 已清理历史"空单元格膨胀"（销售 sheet dimension 曾虚标到 60000 行，`Ctrl+End` 会跳远）——runner 已修复，如再遇到用 `daily_update\fix_bloat.py` 一键清理
- **⚠️ 报告"类型"必须核对，不只是文件名**（2026-10-13 印度实翻车）：后台有两份报告都会叫"管理库存报告"——

  判据：`head -1 报告.csv | grep afn-fulfillable-quantity`，有才是对的。
- **`os.replace` 报 `PermissionError WinError 5` 不用慌**（无 `~$` 也会发生）：runner 已把成品落成 `<文件名>.new.xlsx`，
  直接 `cp -f <文件名>.new.xlsx <文件名>` 覆盖，再删 `.new.xlsx`；覆盖前核 `zip.testzip()`+sheet 名单+锚点。
