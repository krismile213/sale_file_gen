## 三、泰国为什么是 0

不是数据缺失，是**泰国补货做得最干净**：

- 泰国备货表 333 个 SKU，在售 324、售完即止 6、停售 3
- 零库存 26 个，**26 个全部已有在途**（26/26）
- 所以「在售 + 零库存 + 零在途」= 0

对比：印尼零库存 89 个里只有 55 个有在途；菲律宾零库存 67 个里 63 个有在途。

## 七、结论

1. **五份文件的快照日全部是 2026-10-29**，备货表是通过三国库存合计反推确认的。
2. **泰国零缺货**：26 个零库存的品全部已有在途，补货链条最完整。
3. **印尼的问题不在断货，在从未备货**：29 个在售、零库存、零在途、其中 20 个 C 级，属于上架后一直没排产。
4. **菲律宾真断货 3 个**，其中 2 个是 E 级（不该补），实际只有 G566 一个新品值得看。
5. **商品资料与备货表状态零冲突**，可以放心用备货表作分站点在售判据。
