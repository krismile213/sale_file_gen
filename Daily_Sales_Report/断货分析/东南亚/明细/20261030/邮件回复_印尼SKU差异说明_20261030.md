## 一、差异的两个原因

**1. 「在途」含不含计划到货**

我们之前那版用的是日销表里的「剩余库存+在途库存」，这个字段只算**已经发运、在海上漂着的**货；
你表里的 `In transit` 是**含已排产、已下单但还没发运**的计划到货（就是 1104、1118 那几个到货周的数）。

结果就是：一批「排产了但还没发」的 SKU，在我们这边显示零在途，被当成断货了。实际它们有货在路上。

**2. 零销量的 SKU 算不算断货**

你的口径如果是「在售 + 无现货 + 无在途」，会把**今年一件没进、也没卖过**的 SKU 一起算进来。
这类 SKU 我们理解不属于「断货」，是选品/上架的问题，所以单独列了一页，没混进断货清单。

## 二、把印尼的数字摊开看

同样是「在售 + 无现货」的印尼 SKU，按「有没有补货」「有没有卖过」拆成四类：

| 类型 | 定义 | 数量 |
|---|---|---:|
| **A 真断货** | 无现货 + 无在途 + 今年有销量 | **5** |
| B 缺货在补 | 无现货 + **有在途** + 今年有销量 | 35 |
| C 从未备货 | 无现货 + 无在途 + **今年零销量** | 29 |
| D 新备货未开卖 | 无现货 + 有在途 + 零销量 | 20 |

- 你那边如果是「在售 + 无现货 + 无在途」= **A + C = 34 个**
- 我们之前报的是 **13 个**（= A 的 5 个 + B 里的 8 个）
- **两边真正一致的就是 A 这 5 个：G178、G257、G402、G422、G576**

所以不是谁算错了，是我们多算了 8 个「有货在路上」的，你那边多算了 29 个「从来没备过货」的。

## 五、之后的统一口径（建议）

> 在售 = 商品资料对应国家的「状态」列 = 在售
> 库存 = 同页 `In stock` / `In transit`（**在途含计划到货**）
> 断货 = 在售 + In stock ≤ 0 + In transit ≤ 0 + 今年有销量
