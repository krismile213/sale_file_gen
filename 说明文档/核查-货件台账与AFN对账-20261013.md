## 使用方法（以后每天）

```
python .workbuddy/verify_ship_afn.py 20261014        # 每天快照导入后跑一次
```
三道闸的读法：
1. **闸1 有 ✗** → 手工/程序抄错数，立即修（对照 TSV 原始件数）。
2. **闸2 边界/未来层** → 这些票不出现在当天 AFN 里是正常的，别当成差异追查；
   判断某票是否应出现在 AFN：发货日 < 快照日 → 应该在；≥ 快照日 → 不一定/不该在。
3. **闸3 差额为负**（AFN < 手工在途）= 未入网（海运登记滞后，正常）；
   **差额为正** = 有票已到 FC 在收货但没标「到货」→ 去行5 补「到货」二字。
4. **差分行**：净入网 ≈ 某票件数 → 该票已入网；≈ 0 或为负 → 新发货未登记+在收货抵扣。
