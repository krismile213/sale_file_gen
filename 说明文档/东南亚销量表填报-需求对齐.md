## 四、⚠️ 顺带发现并修掉的既有缺陷：`.rels` 悬空关系

重跑后 `openpyxl.load_workbook()` 直接报
`KeyError: There is no item named 'xl/drawings/drawing1.xml' in the archive`。

**成因链**（与本次双语化**无关**，是老代码既有缺陷，只是这次才第一次跑到）：

```
模板 sheet6（= Singapore 新加坡销量表）
  └─ <drawing r:id="rId1"/>  →  xl/worksheets/_rels/sheet6.xml.rels  →  xl/drawings/drawing1.xml
       而 drawing1.xml 里只是一条 hidden="1"、宽度 cx="0" 的「直接连接符 1」(<xdr:cxnSp>)
  ↓ openpyxl 保存
       不支持 <xdr:cxnSp> → 不保留 drawing1.xml，且 sheet6.xml 里的 <drawing/> 也一并去掉
  ↓ restore_wps_parts（[9] 的 WPS 部件还原）
       把模板的 xl/worksheets/_rels/sheet6.xml.rels 原样写回 → 重新指向一个**已不存在的部件**
  ↓ 结果
       悬空关系 → 再次 openpyxl 打开即 KeyError
```

**修法**：新增 `_prune_dangling_rels(part, data, present, blobs)` —— 写回任何 `.rels` 前逐条校验：

- `Target` 解析（`posixpath.normpath`，支持 `../x` 与 `/xl/x` 两种写法）后**在输出包里存在** → 保留；
- **不存在、且引用方 XML 里已无该 `r:id`** → 删掉该条（本次删掉 `rId1 → xl/drawings/drawing1.xml`）；
- 一条都不剩 → **整个 `.rels` 都不写**（记入 `skipped`，"已写回部件"由 13 降为 12）；
- **不存在但仍被引用** → 保留并打印 ⚠️ 告警（不误删）。

> 那条连接符是**纯装饰且被隐藏**，删掉对 WPS/Excel 打开没有任何影响。

**顺带修回的旧版保真损失**：9.15 那版成品丢了 `sheet1` 的 **11 条 x14 条件格式**和**全部行高**；
本次重跑已恢复（条件格式 11 条、迷你图 8 条、行高 `ht="50.1"` 与模板一致）。
